# Лихие

Сайт ботов для SillyTavern, которые живут в одном городе. Петербург, 1996 год.

Сейчас в городе: **Виктор Громов** и **Алексей Тихонов** (история «Почти честные»).

Одна страница без сборки и зависимостей. Разделы переключаются по ссылкам вида `#/viktor`, поэтому всё работает прямо на GitHub Pages.

## Что внутри

```
index.html        весь сайт: комната, каталог, город, инструкция
bots.js           список персонажей: из него собираются папки, личные дела и каналы телевизора
music.js          список пластинок для проигрывателя
music/            песни
assets/           картинки (портреты, двор)
.nojekyll         чтобы GitHub не обрабатывал сайт через Jekyll
```

## Как выложить на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `lihie`.
2. Нажмите **Add file → Upload files** и перетащите всё содержимое архива: `index.html`, `bots.js`, `music.js`, `README.md`, `.nojekyll` и папки `assets` и `music`. Нажмите **Commit changes**.
   Файл `.nojekyll` скрытый. Если он не перетащился, ничего страшного, сайт заработает и без него.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
5. Через минуту-две сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/lihie/`.

## Как добавить нового бота

1. Загрузите портрет в `assets/` (вертикальный, примерно 2:3).
2. Откройте `bots.js` (на GitHub кнопка с карандашом), скопируйте блок любого персонажа от `{` до `}`, вставьте после последнего через запятую и поменяйте тексты. Что значит каждое поле, написано в начале файла.
3. Сохраните. Папка на главной, личное дело и новый канал на телевизоре появятся сами.

Если у новых ботов будет своя общая история, как «Почти честные», её блок с двумя ракурсами добавляется в `index.html` рядом с первой.

## Как выложить карточки

Сейчас карточек на сайте нет: на странице персонажа написано «Карточка пока не выложена». Когда решите выложить:

1. Создайте в репозитории папку `downloads` и загрузите туда PNG, JSON и лорбук.
2. В `bots.js` у нужного персонажа впишите пути в блок `files`, например `"png": "downloads/viktor_gromov.png"`.
3. Сохраните, и на странице появятся кнопки скачивания. Если какое-то поле оставить пустым (`""`), этой кнопки просто не будет.

## Пластинки

На главной стоит проигрыватель с семью пластинками: сначала «Наутилус», потом Высоцкий, «Кино» и Пугачёва. Нажатие на пластинку или на кнопку ▶ ставит её играть, кнопки ‹ › и конверт у столика меняют пластинку. Когда песня кончается, сама встаёт следующая.

Песни лежат в папке `music/`, список в `music.js`. Чтобы добавить песню, положите mp3 в `music/` и допишите строку в `music.js` по образцу.

## Заставка

При первом заходе показывается заставка с пластинкой «Крылья». Пропускается нажатием или любой клавишей и в той же вкладке больше не повторяется.
