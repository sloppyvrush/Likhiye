# Лихие

Сайт ботов для SillyTavern, которые живут в одном городе. Петербург, 1996 год.

Сейчас в городе: **Виктор Громов** и **Алексей Тихонов** (история «Почти честные»).

Одна страница без сборки и зависимостей. Разделы переключаются по ссылкам вида `#/viktor`, поэтому всё работает прямо на GitHub Pages.

## Что внутри

```
index.html        весь сайт: комната, каталог, город, инструкция
bots.js           список персонажей: из него собираются папки, личные дела и каналы телевизора
music.js          список пластинок для проигрывателя
music/            песни
assets/           картинки: портреты, двор, обложки (covers/), вид из окна и кассеты (room/), снимки персонажей и питомцев (people/)
.nojekyll         чтобы GitHub не обрабатывал сайт через Jekyll
```

## Как выложить на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `lihie`.
2. Нажмите **Add file → Upload files** и перетащите всё содержимое архива: `index.html`, `bots.js`, `music.js`, `README.md`, `.nojekyll` и папки `assets` и `music`. Нажмите **Commit changes**.
   Файл `.nojekyll` скрытый. Если он не перетащился, ничего страшного, сайт заработает и без него.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
5. Через минуту-две сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/lihie/`.

## Как добавить нового бота

1. Загрузите портрет в `assets/` (вертикальный, примерно 2:3).
2. Откройте `bots.js` (на GitHub кнопка с карандашом), скопируйте блок любого персонажа от `{` до `}`, вставьте после последнего через запятую и поменяйте тексты. Что значит каждое поле, написано в начале файла.
3. Сохраните. Папка на главной, личное дело и новый канал на телевизоре появятся сами.

Если у новых ботов будет своя общая история, как «Почти честные», её блок с двумя ракурсами добавляется в `index.html` рядом с первой.

## Как выложить карточки

Сейчас карточек на сайте нет: на странице персонажа написано «Карточка пока не выложена». Когда решите выложить:

1. Создайте в репозитории папку `downloads` и загрузите туда PNG, JSON и лорбук.
2. В `bots.js` у нужного персонажа впишите пути в блок `files`, например `"png": "downloads/viktor_gromov.png"`.
3. Сохраните, и на странице появятся кнопки скачивания. Если какое-то поле оставить пустым (`""`), этой кнопки просто не будет.

## Фототаблица и питомцы

В личном деле каждого персонажа есть разворот «Фототаблица»: четыре снимка (в форме, в гражданском, дома и питомец). Нажатие на снимок открывает его крупно. Снимки лежат в `assets/people/`, список в `bots.js`, поле `gallery`. Питомец из поля `pet` сидит на папке персонажа в каталоге: Найда на папке Виктора, кот Пират на папке Лёши. Найда ещё лежит на полу в комнате на главной; если на неё нажать, она виляет хвостом.

## Пластинки

На главной стоит проигрыватель с двенадцатью пластинками: «Наутилус», Высоцкий, «Кино», Пугачёва, «Альянс», «Ласковый май» и ДДТ. У каждой свой конверт с обложкой (картинки в `assets/covers/`). Нажатие на пластинку или на кнопку ▶ ставит её играть, кнопки ‹ › и конверт у столика меняют пластинку. Под комнатой стоит полка со всеми пластинками: при наведении на конверт раскрывается записка с названием, нажатие ставит пластинку на проигрыватель. Громкость регулируется ползунком, на телефонах тоже. Когда песня кончается, сама встаёт следующая.

Песни лежат в папке `music/`, список в `music.js`. Чтобы добавить песню, положите mp3 в `music/` и допишите строку в `music.js` по образцу.

## Город

В разделе «Город» старая карта Ленинграда, где важные места отмечены булавками и связаны красной ниткой: по нажатию на булавку раскрывается записка. Тексты записок лежат прямо в кнопках-булавках (`data-title`, `data-text`) в `index.html`. На телефоне карта показывает только Кировский район и центр, булавки пронумерованы, а под картой список мест: нажатие на строчку открывает ту же записку.

Ниже две доски объявлений, на остановке и у подъезда. Объявления лежат в `index.html`, в блоках `board-grid`; страница сама раскладывает их по колонкам (на телефоне по две) и дорисовывает в пустых местах рисунки маркером и мелом. Надписи и рисунки на самих досках лежат в блоках `band`. Номерки на объявлениях отрываются по нажатию: листок падает, на объявлении остаётся корешок. После обновления страницы номерки снова на месте.

## Телефон

На телефоне комната показывается целиком в полный рост экрана, и её можно листать пальцем влево и вправо: к окну или к серванту и часам. Открывается она на телевизоре. Если добавить к адресу `?room=compact`, будет старый ужатый вариант.

## Календарь

На стене висит календарь на 1996 год, открытый на текущем месяце: сегодняшнее число обведено красным, год всегда 1996-й. По нажатию календарь приближается.

## Заставка

При каждом заходе и обновлении страницы показывается заставка с пластинкой «Крылья». Пропускается нажатием или любой клавишей.
